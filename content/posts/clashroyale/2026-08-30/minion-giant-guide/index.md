皇室战争9月赛季的新卡已经确定，是 **亡灵巨人**。
![皇室战争新卡亡灵巨人](minion-giant.jpg)
简单讲，它就是一个会飞的巨人，4 费，核心，只打建筑，空中远程吐毒。

这张卡看起来平平无奇，但是作为一张空军，以前是没有这个位置的。天狗很肉，但 7 费费用比较高。气球爆发高，但摸不到塔就容易亏。亡灵巨人刚好补齐了空中这个空位，费用低，血量够，输出还不算低。

一起来看一下这张卡牌。

## 基础信息

亡灵巨人是 9 月第 87 赛季的新卡，也是皇室战争 2026 年推出的第二张普通新卡。按照目前的信息，它是稀有卡，费用 4 圣水，属于飞行单位，只会攻击建筑和公主塔。

官方卡牌描述里提到，它是在制造毒素的实验中意外形成的怪东西，会从空中锁定建筑，并在远处吐出毒液。这个设定倒是很符合亡灵一家的味道，从外观、攻击方式到音效都比较恶心。

目前核心数值如下，以 11 级锦标赛标准为准，正式上线前仍然可能调整。

| 项目 | 数值 |
|---|---|
| 费用 | 4 圣水 |
| 稀有度 | 稀有 |
| 类型 | 飞行单位 |
| 目标 | 建筑 |
| 生命值 | 1817 |
| 单次伤害 | 189 |
| 攻击速度 | 1.5 秒 |
| 每秒伤害 | 126 |
| 移动速度 | 中等 |
| 视野范围 | 6.5 |
| 射程 | 4 |
| 质量 | 15 |

光看这张基础表，可能还没那么直观。具体数值强度，和同类卡牌来对比一下。

先拿中型地面单位做个对照。

| 卡牌   | 生命值  |
| ---- | ---- |
| 骑士   | 1766 |
| 亡灵巨人 | 1817 |
| 绿林小哥 | 1832 |
| 女武神  | 1907 |

亡灵巨人的生命值比骑士还高一点，接近绿林小哥和女武神。单独看这不算离谱，但是问题是它会飞。地面单位摸不到它，很多防守牌天然少了一半作用，而空中部队缺乏小皮卡、大皮卡这样的强力 dps 来针对。

再把它放到飞行单位里看。

| 卡牌 | 生命值 |
|---|---|
| 地狱飞龙 | 1295 |
| 气球兵 | 1676 |
| 亡灵巨人 | 1817 |
| 熔岩猎犬 | 3581 |

亡灵巨人比气球兵还肉，约等于半只天狗。雷电法术和火箭单独都打不死它，虚空如果三段完整命中可以处理，但实战里很难单独劈到亡灵巨人，大概率会被炮灰挡枪。

所以这么看，这张卡牌其实防守起来还是很棘手的。防守方如果没有建筑拉扯，或者对空部队，它会是个大麻烦。

## 和天狗正面对比

亡灵巨人很容易被拿来和天狗、气球比较。

天狗是传统空军坦克，费用 7，血量高，主要价值是吸收伤害和带后排。气球是爆发型建筑目标，只要摸到塔就赚。亡灵巨人看上去夹在中间，但使用思路不会完全像这两张卡。

我们来对比一下亡灵巨人和天狗。

| 项目 | 熔岩猎犬 | 亡灵巨人 |
|---|---|---|
| 费用 | 7 | 4 |
| 目标 | 建筑 | 建筑 |
| 生命值 | 3581 | 1817 |
| 移动速度 | 慢 | 中等 |
| 视野范围 | 5.5 | 6.5 |
| 质量 | 5 | 15 |
| 半径 | 0.75 | 0.75 |
| 射程 | 3.5 | 4 |
| 单次伤害 | 53 | 189 |
| 攻击速度 | 1.3 秒 | 1.5 秒 |
| 每秒伤害 | 41 | 126 |

这张表能看出几个很实际的差别。

亡灵巨人的视野范围更大，所以更容易被建筑勾走。只要防守方带建筑，亡灵巨人摸塔效率会明显下降。

它移动速度更快，射程也更远。对面没建筑的时候，它到塔前开吐的速度会比天狗更直接，不需要等到天狗爆掉小狗出上海。

再看输出。天狗本体 DPS 只有 41，大部分对局其实并不依靠天狗本体打伤害，更多是在给后排扛伤害。亡灵巨人 DPS 126，已经可以当成是对塔的主要输出了。从创作者的测试来看，如果公主塔单解，亡灵巨人倒下前大概能打 7 下，总伤害 1323，差不多是公主塔 40% 的血量。

4 费卡能做到这一点，已经足够了。

## 输出效率

再看一张输出对照表。

| 卡牌   | 单次伤害 | 攻击速度  | 每秒伤害 |
| ---- | ---- | ----- | ---- |
| 熔岩猎犬 | 53   | 1.3 秒 | 41   |
| 亡灵巨人 | 189  | 1.5 秒 | 126  |
| 飞行器  | 171  | 1.1 秒 | 155  |
| 皇家巨人 | 307  | 1.8 秒 | 171  |
| 气球兵  | 640  | 2 秒   | 320  |

亡灵巨人没有气球那样的爆发，也没有皇家巨人那种远距离的压制感。它更像一张肉很多的飞行器，进入射程后磨血。

但是这个空中大胃袋还是不能被低估。

它的强度，很大一部分来自它的三个特点。

第一，它会飞，所以地面单位碰不到它。你用骑士、女武神、迷你皮卡这些卡去守，完全没用。

第二，它是核心卡牌，只打建筑，所以不会被普通地面单位拉走。对面如果没有建筑，亡灵巨人会直奔公主塔。

第三，它还是远程攻击，射程 4。这意味着它不一定非要贴脸才能输出。只要走到射程，它就开始吐毒。

这三个特点叠在一起，防守起来真的是有些麻烦。你需要对空，或者是建筑，或者需要合适的法术。

如果你的卡组本来就怕气球、天狗，那亡灵巨人上线以后大概率也会让你头疼。从测试服的实际对战来看，能一对一比较干净处理亡灵巨人的单位并不多，像亡灵大军、觉醒猎人、精英法师这类才比较稳。

粗略估计，如果下赛季亡灵胖子使用率上来，环境里建筑使用率和对空单位都会变多。

## 不被击退

亡灵巨人名字里带巨人，血量相比胖子之类倒是少了不少。普通巨人 11 级有 3968 血，亡灵巨人只有 1817，差距很明显。

但是大胃袋有一个胖子都有的特点，就是重量。

简单说，它对很多击退效果有很强抗性。普通雪球、火球、飞斧屠夫类击退，对它不太好使。它会继续往建筑和公主塔走。

能击退或者拉动它的主要是飓风、觉醒雪球、精英法师、精英巨人这类更强控制卡牌或者法术。

这点很关键。很多时候我们防建筑目标单位，会靠雪球、火球、击退去拖时间。亡灵巨人如果不吃这套，就只能靠建筑、对空或者其他手段来硬解。

## 卡组方向

亡灵巨人上线以后，会对哪些卡组构建有影响呢？我们不妨来脑洞一下～

### 天狗位

![亡灵巨人天狗位卡组参考一](deck-lava-1.jpg)

![亡灵巨人天狗位卡组参考二](deck-lava-2.jpg)

这个思路很明显，把亡灵巨人塞进天狗体系的位置。

这个方向好处是基本不用变附件，飞龙宝宝、飞行器、亡灵、骨龙、矿工、法术，这些东西本来就是现成的天狗构筑。

但是打法思路可能和现有天狗不太一样，不会纯粹跟以前似的沉底天狗然后一波推。毕竟亡灵大胃袋血少很多，跑的还快，不容易攒出一波兵的费用。倒是可以没事磨磨血，循环来打打试探。

### 气球位

![亡灵巨人气球位卡组参考一](deck-balloon-1.jpg)

![亡灵巨人气球位卡组参考二](deck-balloon-2.jpg)

第二个方向是拿亡灵巨人去替气球位。

这个路子就跟以前差别大了，气球进塔就赚，亡灵巨人缺少爆发，比较好的路子应该是亡灵巨人在前面吸引火力，矿工、毒药、飞行器或者其它小单位在旁边蹭伤害。它摸塔赚，不摸塔也能逼对面交牌。


### 替代一些卡组的核心

![亡灵巨人轻型主攻卡组参考一](deck-alt-1.jpg)

![亡灵巨人轻型主攻卡组参考二](deck-alt-2.jpg)

新卡刚上线时，大家最容易先把它塞进老卡组试试。所以可以替代一些常规卡组的核心卡牌来尝试一下。

这种情况下，亡灵巨人会是一张很烦的换路卡牌。你前面刚把建筑或者其他对空交掉，它后面 4 费再来一只。它不需要每波都赚很多，只要稳定蹭血，压力就会累积。

甚至，这张卡牌还可以在一些可以带附核的卡组中充当附核，譬如起到骨球迫击炮中骨球的作用。主打一个骚扰和换路，必要的时候还可以直接去 A 建筑。譬如石头和雷胖可不可以带呢？似乎也是有可能的。

## 强度预期

个人估计，这张卡牌虽然看起来平平无奇，但它很可能会偷偷改变环境。

它逼大家重新考虑两个问题。

你的卡组有没有建筑。

你的对空够不够稳定。

如果你的卡组这俩是弱项，亡灵巨人会让你防守得很难受。它估计一下打不爆你，但是能反复摸塔、逼你多交牌，慢慢你的节奏就被带偏了。想想之前的草丛和骨球，被牵着鼻子走的感觉很难受的。

所以我的初步评价会给到中上。它未必是超模卡，但开发空间很大。

当然，正式上线前数值仍然可能调整。等 9 月赛季开了以后，我们拭目以待。
